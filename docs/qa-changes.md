# 점검 수정 계약 — 2026-11-07

- 자동 로그인 true는 세션·쿠키 30일, false/누락은 서버 세션 1시간·세션 쿠키이다. 쿠키는 HttpOnly/SameSite=Lax, HTTPS에서는 Secure. 로그아웃·비밀번호 변경 때 삭제한다. 서버 재시작 뒤 세션 복원 기능은 없다.
- 회원가입 없음. 계정 추가·임시 비밀번호·역할 변경·사용 중지 권한은 기존 AuthService 기준을 유지한다.
- 이용자 등록·정보 수정·조회는 로그인한 직원에게 유지한다. 종결 `POST /api/service-users/:id/close`와 재개 `POST /api/service-users/:id/reopen`는 팀장·국장만 허용한다. 403 권한, 잘못된/없는 이용자는 404. 재개는 같은 ID의 status를 active, closed_at을 NULL로 바꾸며 과거 기록을 보존한다.
- 활동 시간은 시작 00:00~23:59, 종료는 24:00까지의 HH:mm 분 단위이다. 종료>시작과 활동 간 겹침 금지를 검사한다. 작성 중의 시간 미입력은 허용하고 완료 시에는 필수이다. 24:00을 포함한 종료는 ActivityTime으로 분 단위 검사하며 PostgreSQL TIME에 CAST하여 저장한다. 조회도 문자열로 읽어 JDBC LocalTime의 자정 변환을 피한다. 기존 TIME 컬럼과 CHECK 제약을 유지하므로 신규 Flyway 파일은 없다.
- 이용자 반응은 참여 정도 1개 + 기타 별도 허용이다. 중복 항목은 기존 PK에 맞게 한 번으로 처리한다. 서로 다른 참여 정도가 여러 개면 400. 예전 일지 조회는 막지 않고 저장 전에 선택을 고치게 한다.
- 선택지 제공 표기를 DB 라벨 그대로 반환한다. 입력은 기존처럼 공백 차이를 허용한다.
- 주간 통계는 일요일~토요일 7일 전체, 이전 기간은 시작일의 7일 전이다. 월 경계에서도 짧은 주와 중복 추이 구간을 만들지 않는다. FE 기간 계산과 같은 규칙이다.
- 통계는 종결 이용자의 ID도 조회할 수 있다. 완료 일지 기준·동시 수정 FOR UPDATE/updatedAt 비교·미래 날짜 금지 등 기존 규칙은 유지한다.

## 실행 검증

`gradlew.bat test` 또는 `./gradlew test`로 JUnit 전체를 실행한다. 권한·시간·반응·주차·쿠키 단위 검증과 실제 SQL 통합 검증을 포함한다.

PostgresRoundTripTest는 [Embedded PostgreSQL](https://github.com/zonkyio/embedded-postgres)로 임시 PostgreSQL을 시작하고 운영 Flyway 마이그레이션을 실행한다. 운영 DB·외부 서버에는 접속하지 않는다. 24:00 왕복, 통계 응답, 종결·재개 이력 보존, 실제 두 트랜잭션의 같은 버전 수정 시 1건 성공/1건 409를 검증한다. Windows와 일반 Linux 사용자 환경에서 실행하며 초기 의존성 다운로드와 임시 프로세스 실행 권한이 필요하다.

OneDrive가 build/test-results를 잠그는 경우 빌드 디렉터리를 로컬 임시 폴더로 분리해 실행한다. 실패 결과를 통과로 간주하거나 테스트를 건너뛰지 않는다.
